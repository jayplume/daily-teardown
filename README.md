# Daily Teardown

One pile of parts a day. Rebuild every object faster than everyone else, or turn
anything into a puzzle and challenge a friend.

Built for the Manycore Aholo Global 3D AI Hackathon. Every object in the game is
generated by **Aholo Lux3D**; nothing is modelled by hand.

## How Lux3D is used

| Step | Lux3D capability | Role in the game |
| --- | --- | --- |
| 1 | Text to 3D / image to 3D (G1-Turbo) | Builds the object from one sentence or one photo |
| 2 | Part split | Breaks the model into separate meshes. These are the puzzle pieces |
| 3 | Articulation | Returns a URDF rig with named links, hinge axes and limits. The rebuilt object moves on those joints |
| 4 | Material transfer (optional) | Repaints the object from a second photo |
| 5 | Size prediction | Scales the printable STL to the object's real size |

A full object takes about five minutes. Lux3D objects split into two to five
parts each, so the daily puzzle is a *bench*: up to three objects side by side
with all their parts mixed into one pile.

## Features

Daily bench, three difficulty levels, hints, reference ghost, mystery mode,
ghost races against a friend's saved run, leaderboard, daily streak, result
card, post to X, "how it was made" panel with real step timings, STL export
for 3D printing, and a make-your-own flow with a build queue.

## Run it

```bash
cp .env.example .env.local   # add your key from https://labs.aholo.ai/api-keys
npm install
npm run dev
```

Without a key the game still runs on the bundled objects; only "Make your own"
is switched off.

## Deploy

Any Node host with a persistent disk. Set `AHOLO_API_KEY`, `AHOLO_REGION=com`
and `DATA_DIR` (the mounted disk). On first start the objects in `seed/` are
copied into `DATA_DIR`. `MAX_BUILDS_PER_DAY` (default 12) and
`MAX_BUILDS_PER_VISITOR` (default 2) ration the shared Lux3D account.

## Layout

- `lib/game/engine.ts` three.js game: shatter, drag, snap, joints, STL export
- `lib/server/pipeline.ts` the Lux3D chain and its one-at-a-time queue
- `lib/server/assets.ts` URDF parsing and GLB shrinking
- `components/Game.tsx` the game screen
- `seed/` objects generated with Lux3D that ship with the project
